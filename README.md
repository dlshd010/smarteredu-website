# SmarterEdu Website

This is the final static SmarterEdu coaching website.

## Upload
Upload these files directly to the ROOT of the GitHub repository:

- index.html
- style.css
- script.js
- config.js
- logo.png
- whatsapp-qr.png
- README.md

Do not create an `assets` folder.

## Branding
`logo.png` is the exact logo supplied by SmarterEdu, with its transparent background preserved.

## Contact configuration
Edit `config.js` if contact details ever need to be changed.

## Premium study materials
The Premium section is a front-end interface only. Do not place paid/private PDF links in this public repository. Secure authentication, payment verification and protected file storage are required before selling protected notes.
